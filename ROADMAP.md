# Roadmap

Roadmap items are proposals, not delivery commitments.

## Phase 0 — feasibility

- Canonical agent, identity, knowledge, tool, evidence, and finding models.
- Defensive ZIP and folder ingestion spike.
- Copilot Studio export and GitHub Copilot harness format research.
- Five end-to-end deterministic rules.
- Self-contained HTML report prototype.
- Product threat model.

## Community v0.1

- Command-line scanner for local folders, Git repositories, and exported ZIP packages.
- Discovery of instructions, `SKILL.md`, MCP declarations, tools, and evaluation files.
- At least 20 deterministic rules.
- JSON, SARIF, and HTML output.
- Deliberately vulnerable synthetic examples.
- Windows source-build instructions.

## Community v1.0

- Basic desktop interface.
- At least 30 documented stable rules.
- Configuration comparison.
- Extension contract for community rules.
- Signed releases, checksums, SBOM, and defensive parser test suite.

## Professional v1.0 — separate commercial product

- Delegated Microsoft Entra sign-in.
- Live Power Platform and Copilot Studio inventory.
- Exposure graph across identities, data, tools, connectors, MCP, and channels.
- Encrypted local history and change detection.
- Human-gated synthetic security tests.
- UK assurance profiles and enhanced evidence reports.
- CI/CD, Defender, Sentinel, and optional Purview integrations.

## Not planned for the first release

- Autonomous remediation.
- Automatic agent deletion or quarantine.
- Full enterprise DLP or content classification.
- Production exploitation.
- A claim of certification or guaranteed prevention.
