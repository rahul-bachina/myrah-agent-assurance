# Contributing

Thank you for helping improve practical AI-agent security.

## Useful early contributions

- propose a deterministic security rule with a real configuration signal;
- provide a synthetic vulnerable or clean fixture;
- document a supported agent package format;
- reproduce a false positive or false negative;
- improve threat modelling, privacy, or accessibility documentation.

## Rule proposal format

Include:

1. rule ID and title;
2. affected agent platform or format;
3. exact observable evidence;
4. security impact without exaggerated claims;
5. deterministic detection logic;
6. remediation;
7. positive, negative, and malformed examples;
8. authoritative references.

## Safety

Use fictional organisations and synthetic data. Never submit customer exports, secrets, personal data, access tokens, or exploit code targeting systems you do not own or have permission to test.
